# User guide

WP Updates Notifier checks your site on a schedule and tells you when WordPress, a plugin or a theme has an update waiting. This guide is for the people who install and look after the site.

- [Getting started](getting-started.md): what you need, installing the plugin, the email channel it sets up, sending a test and running a check.
- [Settings](settings.md): how often to check, what to be told about, and what the Status line says.
- [Channels](channels.md): where notifications go. Add, edit, switch off, duplicate and delete channels, send each kind of update to the right one, and the email options.
- [Multisite networks](multisite.md): network activation, the one set of settings, the system cron for a quiet main site and upgrading from 2.x.
- [Muting a plugin or theme](muting.md): stop the notifications about one plugin or theme, always or for one version, and what that does and does not change.
- [How notifications work](how-notifications-work.md): why you hear about each update once, what happens when a send fails, and what a message contains.
- [Settings in code](settings-in-code.md): setting options and channels from `wp-config.php` or environment variables.
- [Troubleshooting](troubleshooting.md): no emails, old data, a system cron, deliverability, a wrong address in a message and more.

If you write code, the [developer guide](../developers/README.md) covers extending the plugin.
