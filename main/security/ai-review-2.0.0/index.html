    AI-assisted security review for 2.0.0¶

    A bounded, read-only source review of the 2.0.0 release candidate, done with the WordPress Security Skills pack (#230). It is advisory: it is not a certification, it gives no release sign-off and it never gates CI. The scripted tools in the security epic and the manual audit sign-off (#228) remain the release gates, and #228 reads this report as one of its inputs.

    Result: no confirmed findings and nothing that needs validation. 33 candidates were rejected, each with the control that stops it. Five hardening recommendations were triaged by hand and all five are tracked in #325.

    To compare a later run with this one, use the same skills pack commit and the threat model, and run the quick profile on the diff since 1002e36 before each later release.

    Hardening recommendations¶

    None of these is a demonstrated vulnerability. Each is defence in depth, and all five are tracked in #325.

    H1. Escape the translated Settings API titles on the General tab. includes/admin/class-settings-page.php:491 passes a translated section title, and :503 a field label, to add_settings_section() and add_settings_field(). Core's do_settings_sections() and do_settings_fields() print titles as given, and translations, language packs included, are a supply-chain input. The channel form already escapes its row titles (class-channel-form.php:621, :662, :751).

    add_settings_section( 'sc_wpun_settings_main', esc_html__( 'Settings', 'wp-updates-notifier' ), null, 'wp-updates-notifier' );
// ...
$title = esc_html( isset( $schema['label'] ) && is_string( $schema['label'] ) ? $schema['label'] : $name )
    . ( Field_Renderer::is_required( $schema ) ? Field_Renderer::required_marker() : '' );

    H2. Read files only for installed plugins and themes. includes/class-update-checker.php:656 builds WP_PLUGIN_DIR . '/' . $key from transient keys, which come from api.wordpress.org data or an add-on filter, and :716 passes theme keys to wp_get_theme(). Before the loops, keep only installed plugins with array_intersect_key( $plugins_need_update, get_plugins() ), and skip themes where ! wp_get_theme( $key )->exists(). Foreign or traversal keys then never reach a file read, and stray filter entries can't produce empty items.

    H3. Treat external values as secret by default for custom field types. includes/admin/class-channel-form.php:569 blanks external values only for the built-in text-like types. A custom type registered through sc_wpun_field_types that receives a constant or environment value, without secret => true or show_external, is passed the resolved value by its add-on renderer. The add-on is trusted and the behaviour is documented (#232), but the safe default depends on the add-on author. Blank external values for every type outside the built-in set unless show_external is true.

    H4. Redact Channel_Instance when it is serialized. Config_Value redacts in __serialize() (includes/class-config-value.php:110-112), but Channel_Instance redacts only in __debugInfo() (includes/class-channel-instance.php:104-113). Instances reach public hooks (sc_wpun_channel_deleted, sc_wpun_notification_sent, sc_wpun_notification_failed), where a logging plugin that serializes hook arguments would capture resolved secrets. A __serialize() that returns the same redacted array closes that path. var_export(), array casts and Reflection still bypass it.

    H5. Apply the http(s)-only link rule to plain text. includes/class-notification-renderer.php:217-219 writes link URLs into plain-text messages with only control characters removed. Markdown already allows only http(s), and HTML uses esc_url. Skip links that markdown_url() rejects, so a third-party update server's javascript: or data: URL never reaches a channel as text that a client might turn into a link.

    Multisite observations (not audited)¶

    2.0.0 supports single sites only (ADR 0008). These points are kept for the 3.0.0 network work (#85) and were not reviewed in depth.

    • Network constants apply to every site. Constant_Source and Env_Source ignore the site id in the context (includes/class-constant-source.php:33-35, includes/class-env-source.php:33-41). A site administrator who creates a channel whose id matches network-wide SC_WPUN_CHANNEL_<ID>__* constants picks up those values. Secrets are used but not shown, and show_external fields (to, from, reply_to, subject_prefix) are shown read-only to that site's administrators.
    • Test sends reach recipients defined for the network. "Send test" is offered on code-defined channels (includes/admin/class-channels-tab.php:407). On a network, a site administrator can send fixed-content test mail to recipients defined at network level, and can point their own channels at any address through the network's mailer.
    • Site administrators without unfiltered_html reach the forms. Every stored value is sanitised and escaped on output, and no raw-HTML write was found.
    • Per-site scoping is already in place. Notices and the values kept after a failed save are scoped per site (includes/admin/class-notices.php:54, includes/admin/class-channel-form.php:783).
    • Uninstall on large networks. uninstall.php:60-69 goes through every site with number => 0, which may be slow on large networks.

    Residual limitations¶

    • Static review only. Core behaviour, such as the capability handling in options.php, Settings API title output and the escaping of the admin title, is cited from its documented contract. Where it mattered, a plugin-side control is cited as the governing one.
    • Not reviewed in this run: multisite network behaviour, the shipped translation PHP files, the example add-on, the build and release pipeline, and dependencies. The threat model covers them separately.
    • Add-on and same-process code is trusted by the threat model. Custom renderers, field types, config sources and filter callbacks were reviewed only for what the plugin guarantees when its API is used as documented.
    • An empty confirmed set means no vulnerability was confirmed in the recorded scope. It does not mean the plugin is secure.
